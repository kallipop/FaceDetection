# Face Detection with OpenCV

A beginner computer vision project built with Python and OpenCV

The program uses the computer's webcam to detect faces in real time and highlights detected faces with a bounding box

# Features
- Real-time webcam feed
- Face detection using OpenCV Haar Cascade
- Grayscale image processing for detection
- Horizontal camera flip
- Custom pink bounding boxes

# Technologies
- Python 3.13.5
- OpenCV 4.13.0.92

# How to run
- Make sure Python is installed
- Install OpenCV: python -m pip install opencv-python
- Run the program: python main.py
- A camera window will open and detect faces in real time
- Press Q to close the application
